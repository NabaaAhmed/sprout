# 🌱 Sprout

**Play it live:** https://nabaaahmed.github.io/sprout/

A pixel-art virtual pet that grows for real when you study.

Run focus sessions, earn Sprout Points, and watch your companion evolve from a Seedling into an Ancient Bloom — powered by your actual study time. No account required — just you and your buddy.

## Features
- Focus timer with custom durations and optional task labels
- Your pet evolves through 4 stages as you rack up study hours
- Shop for food, decor, outfits, and stickers using points you earn
- Journal with a study heatmap, weekly view, and multi-page notebook
- Turn study notes into a pop quiz and earn SP for correct answers
- Streaks that never punish you for missing a day

## Running locally
```bash
npm install
npm run dev
```
Needs Node 18+.

## Tech
Vite + React, Tailwind CSS, Context API + localStorage for persistence.
